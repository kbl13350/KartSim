## 生成提示词

所有图均以对应的原版透明 PNG 作为 **edit target**，使用 `precise-object-edit`，开启透明背景。共同约束：在更高分辨率下保留原图轮廓、朝向、比例、配色和游戏 UI 风格；单个图标居中，边缘清晰；不加场景、背景、边框或水印。每张图的具体描述：

- 刹车：白银色梯形踏板、五条斜槽、浅蓝色上缘高光、左下暖橙色细边和深色底部阴影。
- 红色氮气：倾斜的红色方形徽章，白色 `N2O` 字样、左下橙黄火焰、右下黄色小徽记。
- 蓝色团队氮气：对应的蓝色徽章、白色 `N2O` 字样、淡蓝火焰和右下小徽记。
- 小喷：蓝白半透明弯曲气流，淡紫白高光，深蓝左下弧形边。
- 设置：亮蓝与白色的八齿齿轮和圆形中心孔。
- 方向：蓝灰色左指三角形方向符号，白色内嵌箭头。
- 漂移：蓝灰色圆环和白色弯曲漂移标记。

请勿将重绘版与原版素材混用为同一来源。
